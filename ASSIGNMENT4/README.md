# ASSIGNMENT 4 — Mobile Computing

This folder contains the Assignment 4 materials for Mobile Computing.

## Contents
- Android architecture and app-launch flow diagrams
- Secure messaging and power-state policy diagrams
- Battery energy comparison diagram and sample CSV data
- Kotlin examples for lifecycle logging, image processing, and runtime benchmarking
- Python security-audit and battery-tracking programs
- ADB power instrumentation shell script
- Model answers document

## Running the Python examples
Use Python 3.10 or newer. The programs use the Python standard library only.

```bash
python part2_task4_security_audit.py
python part2_task6_battery_tracker.py
```

See the individual source files for usage notes. Android snippets are reference examples and need to be placed in an Android Studio project with the relevant AndroidX dependencies.
